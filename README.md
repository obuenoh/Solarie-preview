# Solarie — prévia do projeto

Prévia navegável entregue à cliente. Contém duas coisas:

- `site/` — a loja reformulada, montada sobre o catálogo real (402 produtos)
- `painel/` — o painel administrativo de acompanhamento de vendas

## Importante

O painel usa **dados de venda simulados**. Ele não está ligado à Shopify e
não expõe nenhum número real do negócio. A tela de login é demonstrativa e
não protege nada — quando o painel for ligado aos pedidos de verdade, ele
deixa de ser uma página estática e passa a ser um app dentro do admin da
Shopify, onde a autenticação já existe.

Nada de confidencial (auditoria, diagnóstico, memória de negócio, dados
financeiros) vive neste repositório.
